# Запуск ровера через H100

Запускать с Mac, из этой папки outputs — там, где работают SSH-алиасы h100 и rover107.

```
./rover-qwen.sh start --server h100 --rover 107 --strategy 4 --trajectory-steps 8 --task "Get out of the maze." --duration 180
```

--gpu auto используется по умолчанию: при новом запуске выбирается одна свободная H100. --gpu 0 или --gpu 1 фиксирует нужную карту. Уже работающая наша модель переиспользуется. Чужие процессы не останавливаются. Пример с фиксированной GPU:

```
./rover-qwen.sh start --server h100 --gpu 0 --rover 107 --strategy 4 --trajectory-steps 8 --task "Find the box and approach to within 5 centimeters." --duration 180
```

Проверка без движения — та же команда с --dry-run. Стратегия задаётся --strategy 1..4; --trajectory-steps 1..32 — максимум действий только для стратегии 4. Задание произвольное. Переключатель --disable-collision-protection продолжает работать только для стратегии 4, его смысл не менялся.

Остановка прогона: Ctrl+C или отдельная команда:

```
./rover-qwen.sh stop --server h100 --rover 107
```

Модель при этом остаётся загруженной для следующего прогона. Для освобождения GPU после экспериментов:

```
./rover-qwen.sh model-stop --server h100
```

Карта и камера для №107: http://127.0.0.1:18771. Для №80 выбрать --rover 80, сайт будет на порту 18770. По умолчанию без --server используется старый сервер legacy; явный --server legacy сохраняет прежний запуск на двух 3090.
