# ChopTree: локальный probe

Откройте `experiments/choptree_1x500_r100_probe_only.py` и задайте в верхней части
файла `VENV` (подготовленный venv), `MODEL` (каталог весов), `CRAFTIUM` (собранный
Craftium), `RESULTS` (новый каталог результатов) и `GPUS` (список GPU).
Затем запустите файл **без аргументов**:

```bash
python3 experiments/choptree_1x500_r100_probe_only.py
```

По умолчанию: GPU 0, одна среда одновременно, до 500 действий в эпизоде,
100 последовательных независимых повторов. Seeds мира и sampling — 0…99.
При штатном завершении среды раньше 500 действий эпизод сохраняется как есть.
Параметры задаются прямо в файле: `PIPELINES_PER_GPU`, `ACTIONS`, `REPEATS`,
`MODEL_SEED_START`, `WORLD_SEED_START`. Настройки движка — словарь `ENGINE_PARAMS`;
контролы среды, температура, pacing и запись медиа — соседние константы.
Используется прежний API `Runner(...).set_engine_params(...).set_pipeline(...)
.set_concurrency(...).set_results_directory(...).run(gpus=GPUS)`.
Путь результатов должен быть новым. Venv уже содержит mini-SGLang с CUDA Graphs
и установленный Craftium; команда ничего не скачивает и не устанавливает.

Политика: `center-first` + исходная короткая aim-memory, лучший однотокенный
кандидат короткого поиска (2.8 wood / 50 действий, пять эпизодов). Это выбор по
короткому тесту, не обещание качества на новых seeds или длинных эпизодах.
Локально используем настоящие logits всех восьми действий, softmax при T=0.7
и sampling, не argmax. Никаких OpenRouter, top-5 API-logprobs, скрытого raycast,
координат мира на входе модели, масок «правильных» действий или scripted override.

На каждом шаге: предыдущий и текущий RGB 224×224, прицельные метки и увеличенный
96×96 центр текущего кадра, последние шесть action/reward и счётчики. Это не третий
момент времени. Оценка наклона — только сумма собственных команд, не sensor.
Новый KV-блок на решение, после него освобождается; текстовая история не растёт.
KV-пул 65536 токенов (1.25 GiB для этой модели), один текущий короткий контекст.
Длина эпизода не увеличивает число одновременно занятых KV-страниц.

Среда: `Craftium/ChopTree-v0`, frameskip=4, pmul=2, поворот 7°, фиксированный
полдень, sleep(0.1) перед действием. После reset ждём наблюдаемой стабилизации
спавна; эти NOP не входят в бюджет 500 действий. Новый мир и новая feedback-memory
на каждый повтор. Реальная длительность физического шага всё ещё зависит от хоста.
Запуски Luanti сериализованы короткой межпроцессной блокировкой до завершения
native reset. Игровой UDP-порт проверяется через bind и выбирается вне системного
ephemeral-диапазона: случайный выбор Craftium иногда конфликтует с живыми клиентами.
Это не сериализует действия уже запущенных сред.

Сохраняются actions/rewards, положения для последующей диагностики, input hashes,
вероятности действий, engine forwards, GPU util и GIF; отдельные PNG выключены.
GIF показывает исходные кадры, а не увеличенные входы модели.

## Один разбор + действие

Установите дополнительную зависимость формата в выбранный venv:
`uv pip install --python /path/to/minisgl-venv/bin/python xgrammar==0.2.7`.
Затем настройте пути и константы в `experiments/choptree_5x500_r4_assessment.py`
и запустите `python3 experiments/choptree_5x500_r4_assessment.py` без аргументов.
Это самостоятельный файл конфигурации: настройки не импортируются из другого
эксперимента. Его конфигурация не изменена: 5×500×4, seeds 0…19.

Этот вариант генерирует один JSON: короткий `observation`, затем `action`.
Prompt — `assessment-near-wood`, feedback — evidence V5. Текст прошлых разборов
не добавляется в следующие решения. Все токены сэмплируются при T=0.7, top-p=1,
без top-k отсечения. JSON-schema ограничивает только формат, длину разбора
(640 символов) и названия восьми допустимых кнопок — не выбор «правильной» кнопки.
Лимит всей генерации 768 токенов; незавершённый ответ — явная ошибка, не fallback,
не автоматическое повторение и не подмена действия. Сырые разборы пишутся в events.

Выбор по поиску: 4.6 wood в 5×50. В последующем 10×100 было 2.8 к 50-му действию
и 5.1 к 100-му: устойчивые 4+ за 50 действий не подтверждены. Локальная модель
и sampler не обязаны воспроизводить ответы hosted-провайдера.
